A. Pre-Test

1. Jelaskan keudukan CSS dalam pemrograman web.

CSS (Cascading Style Sheets) memiliki kedudukan sebagai bahasa yang mengatur tampilan atau presentasi halaman web. Dalam pemrograman web, terdapat tiga bahasa utama dengan tugas yang berbeda. HTML berfungsi menyusun struktur dan isi halaman seperti judul, paragraf, tabel, dan gambar. CSS berfungsi mengatur tampilan dan tata letak seperti warna, jenis huruf, ukuran, jarak, dan posisi elemen. Sementara itu, JavaScript berfungsi mengatur perilaku dan interaksi pada halaman. Dengan demikian, HTML menentukan apa yang ditampilkan, sedangkan CSS menentukan bagaimana isi tersebut ditampilkan. Pemisahan antara struktur dan tampilan ini membuat kode lebih rapi dan mudah dikelola, karena satu file CSS dapat digunakan oleh banyak halaman sekaligus, dan perubahan tampilan cukup dilakukan di satu tempat tanpa mengubah isi HTML.

2. Berikan masing-masing satu contoh penggunaan css selektor

  • Selektor elemen (Tag) : Digunakan untuk memilih elemen Memilih semua elemen dengan nama tag HTML.

    Contoh :

    h1 {color: blue;}

  • Selektor Class: Digunakan untuk memilih elemen yang punya class tertentu, ditulis dengan titik.

    • Contoh :

    .info { background-color: gray; }

  • Selektor ID: Digunakan untuk memilih satu elemen berdasarkan ID tertentu, di tulis dengan tanda pagar.

    • Contoh :

    #judul { text-align: center; }

  • Selektor universal: Digunakan untuk memilih semua elemen di halaman, ditulis dengan bintang (*).

    • Contoh :

    * { margin: 0; padding: 0; }

  • Selektor grup: Digunakan untuk memilih beberapa elemen sekaligus, dipisahkan dengan koma.

    • Contoh :

    h1, h2, h3 { color: blue; }

Ada 3 cara penulisan CSS, yaitu:

  • Inline CSS : CSS ditulis langsung di dalam tag HTML memakai atribut style

    • HTML

     < !DOCTYPE html >
        < html lang="id" >
        < head >
        < meta charset="UTF-8" >
        < meta name="viewport" content="width=device-width, initial-scale=1.0">
        < title> CSS Inline < / title>
        <  /head > 
        < body >
        < h1 style="color: rgb(255, 0, 51); text-align: center;">
        Biodata Diri
    < /h1 >
    < p style="color: red; font-size: 20px;">
        Ini adalah biodata diri Novita Lestari.
    < /p>
    < /body>
    < /html>
  • Internal CSS : CSS ditulis menggunakan tag < style> pada bagian < head> dalam file HTML yang sama
    •  < !DOCTYPE html >
        < html lang="id" >
        < title> Inline CSS < / title>
        < style>
        < p
            fontfamily: Arial, sans-serif; 
            color: blue;
            text-align: center;
        
        < /style>
  • Eksternal CSS: Ditulis pada file terpisah dengan ekstensi .css, kemudian dihubungkan ke file HTML menggunakan tag < link> 
    •  < !DOCTYPE html >
        < html>
        < head >
        < title> Eksternal CSS < / title>
        < link rel="stylesheet" href="stylesheeet.css">
        <  /head > 
        < body >
        < h1> Belajar Eksternal CSS < /h1>
        < p> ini adalah contoh Eksternal CSS < /p> 
        < /body>
        < /html>
